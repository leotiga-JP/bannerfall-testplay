# Bannerfall — Phase 3.5 Combined Arms

Phase 3 の Objective Warfare をベースに、膠着しやすい戦線を動かすための複合兵科プロトタイプです。

## この版で検証すること

- 後方リスポーンによって「敵部隊を撃破して得た時間」が旗攻撃のチャンスになるか
- 戦列歩兵・騎兵・砲兵の非対称性によって戦線に突破・側面攻撃・砲撃が生まれるか
- プレイヤーとAIがリスポーン時に兵科を変更することで、戦局に応じて軍構成が変化するか
- 騎兵が砲兵を狩り、歩兵が旗を攻撃し、砲兵が密集歩兵を崩す役割分担が自然に生まれるか

## 編成

各陣営20部隊。

- Line Infantry ×14 — 20兵。マスケット、銃剣、斧。旗を破壊できる唯一の兵科。
- Cavalry ×4 — 12騎。高速移動、長距離突撃、ロードキル、強い近接。射撃・旗破壊不可。
- Artillery ×2 — 6兵。低速、長射程、範囲砲撃。移動を止めて約2.3秒展開してから射撃。近接に弱い。

リスポーン後はこの比率に固定されません。AIは現在の味方/敵兵科、旗の危険度、敵砲兵数などを見て兵科を再選択します。

## リスポーン

初期軍は前線寄りに展開済みですが、全滅後の部隊は旗よりさらに後方の Reinforcement Camp から再出撃します。

- 全滅 → 約18秒待機
- 後方キャンプへ再出撃
- そこから前線まで長い行軍が必要

これにより、敵部隊を全滅させた側に「援軍到着までの攻勢時間」が発生します。

## プレイヤー操作

### 共通

- `WASD` — 部隊移動
- `F` — 再整列 / 白兵戦から離脱
- マウスホイール — ズーム
- 中クリックドラッグ — 自由カメラ
- ミニマップ左クリック — その地点へカメラジャンプ
- `C` — 自部隊へ戻る
- `F3` — AIデバッグ表示
- `Z / X / V` — 0.5x / 1x / 2x
- `R` — 再戦

### Line Infantry

- `1` — Musket
- `2` — Bayonet
- `3` — Axe
- Musket + 左クリック — 一斉射撃
- Bayonet + 右クリック/Space長押し→離す — 突撃
- Axe + 敵旗を右クリック — 旗破壊

### Cavalry

- 高速WASD移動
- 右クリック/Space長押し→離す — 長距離突撃
- 突撃中に敵へ接触するとロードキルダメージ
- 敵集団内で勢いを失うと白兵戦へ移行
- 射撃・斧による旗破壊は不可

### Artillery

- 移動速度が低い
- 移動を止めると自動展開
- 展開完了後、左クリック地点へ砲撃
- 長射程・範囲ダメージ・長い再装填
- 近すぎる対象や射程外には撃てない

## リスポーン時兵科選択

プレイヤー部隊全滅時に中央へ兵科選択画面が表示されます。

- `1` Line Infantry
- `2` Cavalry
- `3` Artillery

現在の味方軍構成と、AIが戦況から計算した `RECOMMENDED` 兵科も表示します。何も選ばなければ直前の兵科を維持します。

AI部隊もリスポーン時に同じ考え方で兵科を再選択します。兵科が偏りすぎないようSoft Capを持ち、敵砲兵が多ければ騎兵、敵歩兵が多ければ砲兵、旗攻防が激しければ歩兵の評価が上がります。
