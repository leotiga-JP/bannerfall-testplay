# Bannerfall — Phase 1.8 Rally & Reform

Phase 1.7 の戦列射撃・方向指定突撃・白兵戦に、プレイヤー主導の「離脱」と「再整列」を追加したプロトタイプです。

## 操作

- `WASD`: 戦列移動
- `Mouse`: 戦列の向き
- `Left Click`: 一斉射撃
- `Right Click` または `Space` を長押し: 突撃方向を指定
- 長押しを離す: 突撃開始
- 突撃中 / 白兵戦中に `Right Click`: 戦闘を中止し、敵から距離を取って再整列
- `F`: 現在地付近で再整列。戦死者による戦列の穴も詰める
- `Esc / P`: 一時停止
- `R`: 再戦

## Phase 1.8 の変更点

- 白兵戦が全滅まで固定される仕様を廃止
- 突撃中・白兵戦中の右クリックで Break Off（離脱命令）
- 離脱時は敵から後方へラリーポイントを作り、残存兵がそこへ集結
- `F` で任意タイミングの Reform（再整列）
- 再整列時に戦死者の空席を詰めて、残存人数に応じた二列横隊へ再編
- 再整列中は射撃不可。整列完了後に通常の戦列モードへ復帰
- 突撃先に敵がいなかった場合も、停止後に再整列を行う
