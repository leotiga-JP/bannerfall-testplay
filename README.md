# Bannerfall Phase 1.7 — Directed Charge

Phase 1.6の自動接敵を廃止し、プレイヤーが突撃方向とタイミングを自分で決めるプロトタイプです。

## 操作

- WASD: 戦列移動
- Mouse: 戦列の向き
- Left Click: 一斉射撃
- Right Click または Space を長押し: 突撃方向を指定
- Right Click または Space を離す: 矢印方向へ突撃
- Esc / P: 一時停止
- R: 再戦

## Phase 1.7の主な変更

- マップを 1280 x 720 に拡張
- 敵との距離だけで白兵戦へ自動移行しない
- 右クリック / Space 長押し中、部隊から突撃予定方向へ矢印を表示
- キー/ボタンを離すと最大360pxまで指定方向へ突撃
- 突撃中に敵へ接触、または停止地点の周囲に敵がいる場合のみ白兵戦開始
- 周囲に敵がいなくなると一定時間後に自動で戦列を再編
- 白兵戦は非対称。片側だけが白兵戦を仕掛け、相手側が戦列射撃を続ける状況も発生
- 敵AIは距離維持・射撃・近距離防御射撃・状況に応じた突撃を使い分ける

## 敵AIの考え方

敵は基本的に射撃距離を維持します。プレイヤーの突撃中は近距離まで射撃を温存する場合があり、プレイヤーが再装填中・敵側が人数優勢・距離が適切、といった条件では敵側から突撃する可能性があります。白兵戦を受けたからといって必ず白兵戦で返すわけではなく、戦列状態を維持したまま至近距離射撃を行うこともあります。
