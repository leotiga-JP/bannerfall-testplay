# Bannerfall Phase 3 — Objective Warfare

Phase 2 の「20部隊 vs 20部隊・最大約800兵・独立AI戦場」を、旗を巡る目的型戦争へ発展させたプロトタイプです。

## Phase 3 の検証目的

- 敵部隊の撃破を「勝利そのもの」ではなく、敵旗を破壊するための時間・突破口を作る手段へ変える
- プレイヤーが Musket / Bayonet / Axe を状況に応じて持ち替える操作が直感的か確認する
- 旗攻撃を白兵戦と分離し、斧を持った部隊が明示的に目的物へコミットするゲーム性を検証する
- 全滅した部隊が再出撃することで、局地戦の勝利が「攻撃時間の獲得」につながるか確認する
- AIが攻撃・旗破壊・旗防衛・護衛を自律的に使い分けられるか確認する
- 初見プレイヤーが開始演出とHUDだけで勝利条件を理解できるか確認する

## 勝利条件

敵陣営の Banner HP を 0 にすると勝利です。

兵士・部隊を全滅させても勝利にはなりません。壊滅した部隊は一定時間後に自陣へ再出撃します。

## Banner

- BLUE / RED に各1本
- HP: 1800
- 通常攻撃・射撃では破壊不可
- Axe を装備した部隊の専用行動のみでダメージ
- 同時攻撃人数は最大6名として計算
- 旗攻撃中の部隊は敵へ自動で白兵戦を仕掛けず、敵の迎撃に対して無防備になりやすい

## Hotbar

- `1` Musket — 左クリックで一斉射撃
- `2` Bayonet — 右クリック / Space 長押し → 離して突撃
- `3` Axe — 敵旗を右クリックして旗破壊命令
- `4`〜`9` は今後の装備用スロット

武器選択は画面下中央のホットバーに常時表示されます。

## Respawn

- 部隊が 0/20 になると SQUAD WIPED
- 約18秒後に自陣側へ20/20で再出撃
- 再出撃直後は約2.5秒の簡易スポーン保護
- プレイヤー部隊も同じルール

## 初回UX

開始直後は戦闘を停止し、短いカメラ演出を行います。

1. 自軍旗を表示
2. 敵陣へカメラ移動
3. `ENEMY BANNER` / `この旗を破壊すれば勝利`
4. `[3] AXE を選択 → 敵旗を右クリック`
5. プレイヤー部隊へカメラ復帰

その後は常設の目的文章を表示せず、旗HP・ホットバー・状況依存ヒントでプレイを誘導します。

## HUD

- 右上: BLUE / RED Banner HP
- 左下: プレイヤー部隊人数・状態・装備
- 下中央: 9スロットHotbar
- 上中央: 旗攻撃など重要イベントの短い通知
- 旗攻撃時のみ: 目的進行状況を表示
- 右下: Tactical Map

## Minimap / Camera

- Mouse Wheel: ズーム
- Middle Mouse Drag: 自由カメラ
- Minimap Left Click: クリック地点へカメラジャンプし FREE CAMERA に切替
- `C`: プレイヤー部隊へ戻って FOLLOW CAMERA

ミニマップには両軍部隊・プレイヤー・両軍旗・現在のカメラ範囲を表示します。

## AI

各部隊は Phase 2 の射撃・前進・後退・側面移動・突撃・再編に加えて、以下を判断します。

- ATTACK-BANNER: 敵旗周辺が開いた時、斧で旗破壊を試みる
- DEFEND: 自軍旗が攻撃されると近い部隊が迎撃へ向かう
- ESCORT: 味方が旗を攻撃している場合、周囲の敵を排除する

一度に敵旗へ斧で殺到するAI部隊数には上限を設けています。

## その他操作

- WASD: プレイヤー部隊移動
- F: 再整列 / 旗攻撃中止
- Right Click during charge/melee: 離脱
- F3: AIデバッグ表示
- Z / X / V: 0.5x / 1x / 2x
- Esc / P: Pause
- R: Restart
